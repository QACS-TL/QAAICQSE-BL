# Lab 4 - Policy development

**Group exercise:** create a responsible AI coding policy.

**Challenge project:** organizational AI governance framework.

**Scenario:** Your organization is adopting AI-assisted development tools across multiple teams. Create policies that balance productivity with risk management.

## Scenarios

- **Team A, financial services:** PCI DSS, customer financial data, regulatory audit
- **Team B, healthcare:** HIPAA, patient data, medical device software
- **Team C, government or defence:** clearance, data sovereignty, supply chain security
- **Team D, e-commerce or retail:** GDPR and CCPA, payment processing, customer privacy

## Each policy should cover

1. **AI tool selection and approval** - approved tools, evaluation criteria, data handling, vendor assessment
2. **Code provenance and IP** - attribution, licence checks, intellectual property risk, similarity detection
3. **Quality and security gates** - review of AI-generated code, automated scanning, human oversight, security testing
4. **Training and competency** - AI literacy, security awareness, code review, ongoing education
5. **Incident response and audit** - AI-related incidents, audit trail, compliance reporting, breach notification

## Challenge questions

- How do you balance developer productivity with security requirements?
- What happens when AI generates code that violates licensing terms?
- How do you enforce the policy consistently across global teams?
- What metrics show that AI governance is working?
- How do you handle AI-generated code in legacy systems?
